Settings

Read from environment variables. Nothing is stored in the database — this page reports what the process can see, it can't set it.

Where the keys go

Put them in a .env file in the project root — copy .env.example to .env and fill it in. It's read at startup, so restart the server after editing. A variable already set in your shell wins over the file.

{% if env_file_found %}Found and loaded{% else %}No .env file yet{% endif %} — {{ env_file_path }}

Prefer the shell? Set them in the same terminal you start the server from, then launch it there — a new terminal won't have them. 

$env:FIRECRAWL_API_KEY = "fc-..."      # PowerShell
export FIRECRAWL_API_KEY=fc-...        # bash / zsh

LinkedIn policy

This app has no LinkedIn credentials, no scraper and no third-party LinkedIn provider. Activities are typed or pasted in by a person on the contact's page — link plus the text of the post. There is no setting here to change, by design.
