Settings

Enter your API keys here. They are written to .env and used straight away — nothing is stored in the database, and no restart is needed.

Where they are kept

In a .env file in the project root, written by the form below. Editing that file by hand still works; it is read at startup, so restart the server after doing it that way. A variable exported in your shell wins over the file at startup — so if a key looks stuck at an old value after a restart, that is where to look.

{% if env_file_found %}Found and loaded{% else %}No .env file yet{% endif %} — {{ env_file_path }}

Prefer the shell? Set them in the same terminal you start the server from, then launch it there — a new terminal won't have them. 

$env:ANTHROPIC_API_KEY = "sk-ant-..."   # PowerShell
$env:FIRECRAWL_API_KEY = "fc-..."
export ANTHROPIC_API_KEY=sk-ant-...     # bash / zsh
export FIRECRAWL_API_KEY=fc-...

LinkedIn policy

This app has no LinkedIn credentials, no scraper and no third-party LinkedIn provider. Activities are typed or pasted in by a person on the contact's page — link plus the text of the post. There is no setting here to change, by design.
